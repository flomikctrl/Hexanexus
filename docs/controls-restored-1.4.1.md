# Hexanexus 1.4.1 — восстановление управления из Git

22 ноября 2026. Без commit, push, тега и публикации.

## Источник и резервные копии

Использован реальный коммит `b8b0e08b8e7d7ad66592ce1501594741a462d881` — опубликованная Hexanexus 1.4.0 «Новая грань», до добавления удаления удержанием. Код извлечён через `git show`, а не воссоздан по памяти.

До изменения сохранены:

- `.tools/controls-restore-backup/workspace.tar` — рабочие файлы, включая незакоммиченные изменения и пользовательские архивы;
- `.tools/controls-restore-backup/working-tree.patch` — бинарный diff относительно HEAD;
- `.tools/controls-restore-backup/Hexanexus-v1.4.1-before.apk` и `Hexanexus-v1.4.1-before-test.apk` — прежние сборки;
- `.tools/restore-phone-fresh-before.tar` и JSON — свежие данные A55. Старые копии сохранений не восстанавливались.

## Что восстановлено

- `src/interaction.ts` целиком: ClickGesture, PointerTapGesture и применение выбранного инструмента побайтово совпадают с коммитом. Не добавлялись пороги или задержки. SHA-256 исходного файла: `9765297b6130764a8584aae21645172568f1296992e1fe14e3b74f89f6e6c2d3`.
- `src/scene.ts`: обработчики pointerdown/move/up/leave/cancel/lostpointercapture и blur, а также setInteraction возвращены из коммита. Убраны перехват движения в capture-фазе, stopImmediatePropagation и запоминание pressedCell.
- В обработчиках оставлен лишь существующий наблюдательный callback поворота камеры для обучения. Он не ограничивает установку и не изменяет распознавание тапа.
- Переключение «Поставить / Удалить» в main.ts уже совпадало с коммитом; проверено сравнением, переписывать его не потребовалось.
- Вернулась установка по грани пользовательского кубика: `else if(hit.face)` вместо запрета для `userData.placed`. Именно этот запрет в новых попытках делал обычное касание такого кубика бесполезным для продолжения конструкции.

Удержание не удаляет. В старой схеме отпускание пальца после неподвижного удержания может интерпретироваться как обычный клик и поставить соседний блок — таймера и отдельного действия long press нет.

## Что сохранено

Исправление четвёртого яруса не откатывалось: доступная пустая клетка перед дальним кубиком сохраняет приоритет при более близком проецируемом центре. Проверка исходников подтверждает, что весь метод pick сохранён относительно резервной копии, кроме возврата установки по грани добавленных блоков.

Не возвращались старые подсветки/анимации удаления. Не изменялись экономика, костюмы, музыка, уровни, интерфейс, обучение и сохранения. Версия осталась 1.4.1, versionCode 7. Файл scene.ts целиком не откатывался.

## Проверки

- 554 теста в 29 файлах, TypeScript-check, production build, Android test/release builds — успешно.
- Автоматически проверены все шесть граней пользовательских блоков в 3×3×3 и 4×4×4, все ярусы и крайние позиции, исходный сбой II-02 и повороты фигуры. Тесты предыдущих экспериментов обновлены под фактически возвращённую историческую семантику.
- A55: 10/10 последовательных установок в разные разрешённые клетки через ADB, переключение двух режимов, удаление одним коротким касанием, защита основы, отсутствие удаления удержанием, свайп без установки, отмена, все четыре яруса 4×4×4 и три яруса 3×3×3.
- Четвёртый ярус на A55 проверен установкой над пользовательскими блоками, после поворота камеры и завершением II-02 через ранее проблемную клетку `[0.5,1.5,0.5]`.
- Игровые проверки выполнялись в копии localStorage в памяти. После её отключения и полного перезапуска все настоящие ключи совпали со свежим снимком: 280 гексиков, кампании 30/30 и 13/30, семь подарочных костюмов, надета Мотя-кондитер. Награды и покупки не применялись к основному профилю.
- Веб-ресурсы диагностического и финального release APK побайтово совпали. Сертификат и applicationId сохранены.
- Финальный release APK установлен через `adb install -r`, считан с телефона и сверён с локальным по SHA-256. После холодного запуска через UI подтверждены 280 гексиков, кампании 30/30 и 13/30, коллекция и Мотя-кондитер. FirstInstallTime сохранился; телефон оставлен в главном меню.
