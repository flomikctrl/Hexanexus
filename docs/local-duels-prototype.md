# Дуэли Моти: LAN-прототип, этап 1

Это отчёт первого этапа. Текущий APK обновлён: [Android-хост и проверка двух телефонов](android-duels-prototype.md).

Ветка `feature/local-duels`, основа — стабильная 1.5.0 (`873734d`). Это тестовая версия `2.0.0-prototype.1`, Android versionCode 12. Публикации, тега и коммита прототипа нет.

## Запуск двух игроков

1. На ПК выполните `start-duels.cmd` либо `npm.cmd run build` и `npm.cmd run duels:host`.
2. Сервер напечатает адрес, например `http://192.168.0.106:8787`. Откройте его в браузере ПК.
3. На ПК откройте «Дуэли Моти», создайте комнату. На телефоне в этом разделе введите **адрес ПК и порт**, затем четырёхзначный код комнаты.
4. Оба игрока нажимают «Готов». После подготовки обеих сцен начинается общий отсчёт 3–2–1. Матч идёт до двух побед, максимум три раунда. Следующий раунд и реванш требуют согласия обоих участников.

ПК по Ethernet и телефон по Wi-Fi должны видеть друг друга в одной сети. Код комнаты не ищет компьютер. Автообнаружения нет. Можно выбрать интерфейс переменной `DUEL_HOST` и порт `DUEL_PORT`. Сервер слушает один частный IPv4, не `0.0.0.0`; проброс портов роутера не нужен. Если Windows блокирует Node, разрешение входящего подключения требуется только в частной сети. Автоматических изменений брандмауэра нет. Остановка — Ctrl+C; фоновой службы нет.

Тестовый APK: `release/Hexanexus-v2.0.0-prototype.1-test.apk`. Он устанавливается поверх прежней версии с тем же applicationId и сертификатом. Удалять приложение не нужно.

## Архитектура

- `src/duels/room-server.ts` — чистая серверная машина состояний. `scripts/local-duels.mjs` — HTTP для готовой браузерной сборки и WebSocket `/duels`, без Vite dev server/HMR. TypeScript-ядро собирается Vite в памяти при запуске Node.
- `protocol.ts` — проверка сообщений, адресов и профилей. Максимум 8 комнат, 2 игрока в комнате, 16 соединений, 8192 байта в сообщении, 40 сообщений/секунду на соединение. Сервер доступен только частным адресам; это доверенная LAN, без TLS, аккаунтов и защиты от враждебного владельца ПК.
- Сервер выбирает одну из первых шести проверенных задач кампании I. Начальная фигура, доступные позиции, лимит и проекции одинаковы у обоих. Генератора случайных непроверенных фигур нет.
- `client.ts` проверяет серверные данные, подтверждает подготовку и оценивает сдвиг часов. Источник результата — время приёма решения сервером после общего старта.
- Сервер проверяет фактический набор добавленных кубиков: границы, лимит, отсутствие дублей/фиксированных кубиков, связность по граням и победу через существующий `Puzzle`. Совпадение с эталонной конструкцией не требуется. Первый корректный ответ фиксирует раунд один раз; ошибочное решение не завершает его.
- `ui.ts` использует существующие `Scene`, `Puzzle` и обработку управления. Движения камеры не передаются. Подсказки отключены. Гексики, кампании, достижения, рекорды и костюмы дуэлью не изменяются.
- Закрытие комнаты хостом завершает её для обоих. Обрыв активной игры прерывает матч без технической награды. Автоматический возврат с секретным токеном возможен в пределах 15 секунд для хоста и 30 для гостя, после чего можно согласовать реванш. Комнаты живут в памяти сервера: перезапуск Node и полный перезапуск приложения не восстанавливают матч.

## Кубки

Отдельная модель `rating.ts`, ключ `hexanexus.duels.rating.v1`: +25 за победу, −10 за поражение с минимумом 0, матчи/победы/поражения/серии. Винрейт вычисляется из побед и матчей. Ранги: Бронза, Серебро (100), Золото (250), Платина (500), Алмаз (1000); пороги предварительные.

Запись целого результата атомарна в одном JSON, идентификаторы матчей исключают повторное начисление после повторного сообщения или перезапуска. **Постоянное начисление в UI пока выключено** (`persistentDuelRating=false`). Технические отключения не начисляют кубки. Гексики с рейтингом не смешиваются.

## Android и будущий хост на телефоне

В debug-манифест добавлен только `INTERNET`. Незашифрованный LAN WebSocket и mixed content разрешены только тестовой debug-сборке; основной release-манифест остаётся без этого разрешения. Origin приложения `https://localhost` сохранён, поэтому WebView видит прежние сохранения. Геолокация, Bluetooth, Wi-Fi-сканирование, фоновые службы и `ACCESS_NETWORK_STATE` не используются.

Текущий target — 36. При будущем повышении target до Android API 37 потребуется отдельно внедрить разрешение локальной сети согласно [документации Android](https://developer.android.com/privacy-and-security/local-network-permission).

Для Android ↔ Android понадобится нативный Capacitor-плагин WebSocket/HTTP-хоста и управление его жизненным циклом. Чистое ядро комнат и протокол можно сохранить; обычный WebView сам не открывает слушающий TCP-сервер. Обнаружение соседнего телефона — отдельный будущий этап.

## Проверки

- 585 автоматических тестов в 34 файлах, включая 13 тестов дуэлей: комнаты, лимиты, готовность, старт, решения, дубли, счёт, реванш, разрыв, токены, закрытие и атомарный рейтинг. TypeScript, production build и подписанный Android test build успешны.
- Реальные ПК-браузер ↔ Samsung A55 через `192.168.0.106:8787`, без ADB reverse: полный матч 2:1, реванш 0:2, одинаковые задачи и старт, реальные клики мышью/касания ADB, обрыв соединения, автоматический возврат и новый матч после возврата. Отчёт: `artifacts/duels-real-lan.json`.
- На A55 обе обычные кампании проверены с сетевым доступом WebView, отключённым через DevTools: победа, анимация, просмотр, переход дальше, выход домой и отсутствие повторной награды. Это эмуляция отсутствия сети, а не физическое выключение Wi-Fi. Проверки выполнялись в копии профиля в памяти, затем возвращён обычный профиль. Отчёт: `artifacts/duels-offline-win-navigation.json`.
- На итоговом APK также пройдено обучение реальными касаниями, проверены четыре материала/фона, установка/удаление/отмена, обе кампании и запуск бесконечного режима. Реальное хранилище при этих проверках заменялось только временной копией в памяти. Отчёт: `artifacts/duels-regression-phone.json`.
- Полный набор реальных ключей сохранений сравнивается до и после проверок. Актуальная исходная точка: 280 гексиков, кампании 30/30 и 19/30. Старые резервные копии не восстанавливались.
- APK: 52 610 623 байта; SHA-256 `f49454c65d466ee65d4a191643d6fa849fe73377ee5e839edb17cbe0959171ca`. ApplicationId `com.hexanexus.puzzle`, прежний сертификат SHA-256 `7fd9293ff232d5623937b05a6da52032092900a8de241db1c9fcdfca12218c68`. Проверена комплектность 60 уровней, 36 спрайтов, музыки и иконок.

Ограничения этапа: только ПК-хост, ручной LAN-адрес, короткие задачи 3×3×3, нет постоянного рейтинга и сохранения сетевой сессии после перезапуска. Это рабочий локальный прототип, не публичный релиз 2.0.
