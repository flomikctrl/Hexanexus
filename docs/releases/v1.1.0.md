# Hexanexus 1.1.0 — Мастерская Моти

Крупное обновление пространственной головоломки!

- Новый плюшевый помощник Мотя вместо Фиби.
- Гардероб: шесть основных костюмов и три эмоции для каждого.
- Эксклюзивная Королева Мотя за прохождение всех 30 уровней; старый завершённый прогресс тоже учитывается.
- Компактный мобильный интерфейс: «Подсказка» показывает допустимые прозрачные ячейки прямо на конструкции.
- Новая иконка с Мотей-волшебницей и сияющим кубиком.

В игре — кампания из 30 головоломок, свободный осмотр конструкции и уютная фоновая музыка с настройками. Игра полностью работает без интернета: ресурсы встроены в APK. Редактор уровней доступен только в режиме разработки.

**Установка:** скачайте `Hexanexus-v1.1.0.apk`, откройте на Android 7.0+ и при необходимости разрешите установку из выбранного источника. Дополнительные файлы не нужны. Для обновления устанавливайте поверх прежней версии, **не удаляя приложение**: прогресс и костюмы сохранятся.

Сборка release без отладки, с прежним сертификатом подписи для совместимости обновлений. 190 автоматических тестов, TypeScript, production build и проверка ресурсов/подписи APK пройдены.
