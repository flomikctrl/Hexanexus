# Мотя — оригинальные спрайты пользователя

Все 18 PNG извлечены без редактирования из предоставленного пользователем архива `motya_6_skins_18_emotions.zip`.

Шесть костюмов: classic, sleepy, baker, winter, wizard, cosmic. В каждом: idle.png, sad.png, shock.png. Изображения RGBA, 1024×1024, с прозрачным фоном и общим холстом.

Каждый файл уже содержит готового персонажа. Костюмы не собираются слоями; одновременно отображается один PNG.

Каталог скинов, редкости и способ получения описаны в `src/motya-skins.ts`. Все костюмы доступны бесплатно. Проверка прозрачности и хешей: `npm run motya:validate`.

Королева Мотя: `royal/idle.png`, `royal/sad.png`, `royal/shock.png`, оригинальные RGBA PNG 1254×1254 из предоставленного `motya_royal_3_emotions.zip`. Файлы не перерисовывались и не масштабировались. Это седьмой, эксклюзивный образ только за завершение 30 уровней; он не входит в подарки и не продаётся.
