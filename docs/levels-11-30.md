# Уровни 11–30

Первые десять испытаний сохранены. Все новые задачи рассчитаны на обычную установку по граням; ошибочные ходы остаются разрешены. Никакие ячейки не ограничиваются эталонным решением.

Группы: 11–15 — пространственные хитрости; 16–20 — обман проекций; 21–25 — трудные маршруты; 26–30 — финальные испытания.

Минимум — точный результат поиска разрешённой последовательности добавлений. Число вариантов — все легальные ходы, включая ошибочные. Подробные контрольные ходы, кратчайшие решения и варианты на каждом шаге записываются командой `npm run levels:validate` в `artifacts/levels-validation.json`. Эти показатели не доказывают объективную психологическую сложность.

Валидатор сравнивает фиксированную основу и объём, допустимый силуэтами, под всеми поворотами и отражениями куба (48 симметрий). Дубликатов задач не обнаружено. Альтернативные конечные конструкции разрешены, если соблюдены запас, связность и оба силуэта.
