# Hexanexus 1.4.0 — четыре новых подарочных костюма

Локальный тестовый этап от 16 ноября 2026. Push, тег и GitHub Release не выполнялись. На Samsung Galaxy A55 оставлена актуальная тестовая сборка.

## Каталог и ресурсы

| ID | Название | Редкость |
|---|---|---|
| flower | Цветочная Мотя | Обычная |
| pirate | Пиратская Мотя | Редкая |
| night | Ночная Мотя | Легендарная |
| archdemon | Мотя-архидемон | Легендарная |

Три эмоции каждого костюма извлечены из `Motya_Gacha_4_New_Skins_1.4.0.zip` в `public/assets/motya/<id>/idle.png`, `sad.png`, `shock.png`. Всего 12 костюмов и 36 PNG. Прежние 24 изображения не изменялись. Мотя-архитектор полностью интегрирована и остаётся наградой второй кампании; дубликата нет. Королева — награда первой, классическая Мотя бесплатна. Эти три образа не входят в подарки.

У Ночной Моти в исходном холсте 1024×1024 персонаж занимал примерно треть ширины. Для трёх эмоций удалены только прозрачные поля: одинаковая область `(342,342,340,340)`, без ресайза и перерисовки. Попиксельная проверка подтвердила полное совпадение каждого оставленного RGBA-пикселя с оригиналом и нулевую альфу всей отброшенной области. Остальные девять новых PNG сохранены без изменения. Теперь персонаж читается в карточках и предпросмотре. Общие CSS, `object-fit: contain`, декодирование по требованию, кеш, переключатель одного img и анимации переиспользуются.

## Подарки и старые сохранения

Каталог расширен с пяти до девяти ID, старые ID и квитанции не перенумерованы. Формат `gifts` версии 1, `owned`, `sequence` и `pending` сохранён; новый ключ или повторная миграция покупок не нужны. Старое полное `owned` из пяти нарядов остаётся тем же массивом, а знаменатель коллекции вычисляется из каталога: 5/5 → 5/9. Счётчик всех нарядов в профиле динамический: X/12. Подарочный — X/9.

Коробка стоит 300 гексиков. Выбирается редкость с весами 60/25/15, затем равномерно один из оставшихся нарядов этой редкости. Если редкость собрана, её вес исключается. Последний костюм гарантирован, при 9/9 покупка блокируется. Никаких дополнительных гарантий не введено. Интерфейс показывает вероятности после нормализации и список доступных костюмов в подсказке редкости. При старых 5/5 остаются Цветочная 60%, Пиратская 25%, Ночная и архидемон по 7.5%.

Списание и владение записываются одной транзакцией существующей экономики. Защита от повторного тапа, незакрытый подарок, восстановление результата после перезапуска и отказ записи сохраняют прежние правила.

## Реальный Samsung Galaxy A55

A55 (SM-A556E) подключён по ADB. До обновления прочитано фактическое состояние: **55 гексиков**, пять подарочных нарядов baker/winter/wizard/sleepy/cosmic, имя Flom, аватарка classic/IDLE, звание master, рамка plain, первая кампания 30/30. Резервная копия `app_webview`, `files`, `shared_prefs` сохранена локально в `.tools/gacha-140-phone-before.tar`, отдельно сохранён снимок localStorage. Резервные копии не входят в исходники, APK или публикацию.

APK установлен через `adb install -r`, без удаления приложения и без очистки данных. Установка исходной сборки и финальное обновление с исправленным холстом Ночной Моти завершились успешно. Последующая проверка SHA-256 установленного `base.apk` подтвердила совпадение с финальным APK. Сертификат и applicationId сохранены.

В настоящем Android WebView проверены:

- Открытие гардероба, 12 карточек, все три эмоции каждого из четырёх новых костюмов, запрет надевания закрытых.
- Корректный размер Ночной Моти, один экземпляр помощницы, видимость новых карточек при прокрутке и отсутствие горизонтального обрезания.
- Вкладки гардероб/подарки, **5/9**, **55 гексиков**, цена **300**, шансы **60/25/15**, запрет покупки при недостатке средств.
- Профиль Flom, коллекция 7/12 и подарки 5/9, 12 вариантов аватарки и блокировка новых.
- Native Back через Android key event: редактор → профиль → меню, уровни → кампании → меню. Доступность обеих кампаний и открытие списка «Новая грань». Прохождение уровней на основном профиле не проводилось.
- Визуально просмотрены скриншоты заголовков, вкладок и системной строки: перекрытия не обнаружено.
- Холодный перезапуск приложения. Все прежние ключи сохранений и старые поля кошелька сравнивались до/после, затем весь снимок после миграции — до/после UI-проверок и перезапуска. Совпадение подтверждено. Новая служебная секция `campaign2` добавлена штатным чтением второй кампании; старые данные не заменялись.
