# Hexanexus 1.3.0 — Подарки Моти

Добавлены **гексики** и семь достижений: стартовые 50, по 20 за первое прохождение уровня, по 5 за каждый решённый раунд каждой партии. Старые завершения и рекорды учитываются автоматически. Первая подсказка на каждом уровне бесплатна один раз, последующие стоят 2 гексика. В Мастерской Моти можно открыть подарок за **300 гексиков**: один новый костюм без повторов. Пять прежних тестовых нарядов теперь получаются из подарков; классическая Мотя бесплатна, Королева остаётся наградой кампании. Правила и проверки подарков: [docs/gifts-1.3.0.md](docs/gifts-1.3.0.md); экономика: [docs/economy-1.3.0.md](docs/economy-1.3.0.md).

Подписанный автономный APK: `release/Hexanexus-v1.3.0.apk`, Android 7.0+, versionName 1.3.0, versionCode 4. Сборка: `npm.cmd run android:release`. [Описание версии 1.3.0](docs/releases/v1.3.0.md). При обновлении устанавливайте APK поверх прежнего приложения, чтобы сохранить прогресс.

Финальные проверки и параметры подписанного релизного APK: [docs/release-validation-1.3.0.md](docs/release-validation-1.3.0.md). Предыдущие отчёты этапов разработки содержат сведения о тестовых сборках.

Главное меню содержит три действия: **Кампания**, **∞ Бесконечная мастерская**, **Мастерская Моти**. Выбор уровней, достижения и настройки доступны через **≡**. Баланс находится справа сверху и открывает объяснение экономики. Фигура в центре вращается пальцем или мышью; спустя паузу возвращается плавное автовращение. Мастерская объединяет гардероб и работающую вкладку **Подарки** с актуальными шансами редкостей, короткой анимацией и кнопкой «Надеть».

Декоративная фигура вращается только горизонтально: быстрый свайп раскручивает её по инерции, затем движение плавно затухает. Android Back закрывает окна, возвращает из разделов и переключает паузу игры. В главном меню для выхода нужны два нажатия в течение двух секунд. Вращение и рендер оптимизированы; 377 тестов и проверка A55 описаны в [docs/qol-1.3.0.md](docs/qol-1.3.0.md).

Автономная 3D-головоломка на TypeScript, Three.js и Vite: дополните конструкцию, чтобы совпали две ортогональные проекции. В кампании 30 уровней; первые десять и существующие идентификаторы сохранений сохранены.

На Android весь интерфейс размещается в общей безопасной области WebView: системные панели и вырезы учитываются нативно, включая прокрутку и модальные окна. Проверено на A55 и мобильных ширинах 360/390/430 px. Актуальный APK и подробности: [docs/safe-area-1.3.0.md](docs/safe-area-1.3.0.md).

Добавлен отдельный режим **∞ Бесконечная мастерская**: один ход на задачу, три жизни, таймер, рекорды и продолжение сохранённой партии. Кампания и её сохранения отделены от аркады. Подробности, проверки и статистика: [docs/arcade-1.2.0.md](docs/arcade-1.2.0.md). Описание стабильной версии: [docs/releases/v1.2.0.md](docs/releases/v1.2.0.md).

## Запуск на ПК

Запустите `start.cmd`. Он использует переносимый Node.js из `.tools`, если тот присутствует, либо системный Node.js 22.12+.

```sh
npm.cmd ci
npm.cmd run dev
```

Адрес указан в строке **Local:**, обычно http://127.0.0.1:5173/. Если порт занят, Vite выберет следующий. В PowerShell используйте `npm.cmd`, чтобы не зависеть от политики выполнения `.ps1`.

## Игра и управление

Главное меню: **Кампания**, **∞ Бесконечная мастерская**, **Мастерская Моти**. Через **≡** доступны **Выбор уровней**, **Достижения**, **Настройки**. «Кампания» запускает прежнюю игру с 30 уровнями. Версия отображается внизу меню и в настройках. Инструкция доступна из настроек и меню паузы.

- В режиме «Поставить» нажмите на грань существующего кубика. Блок присоединяется только общей гранью внутри сетки 3×3×3 и при наличии запаса. Ошибочные с точки зрения силуэтов ходы разрешены.
- В режиме «Удалить» можно вернуть свой кубик в запас, если остальные добавленные кубики не потеряют связь с неподвижной основой. Фиксированные кубики защищены.
- Перетаскивание вращает камеру, колесо или pinch меняет масштаб. Конструкция и вычисляемые проекции при этом неподвижны. Камеру можно обвести сверху и снизу.
- Каждое нажатие «Подсказка» открывает один следующий шаг решения кампании: золотой + — поставить, оранжевый − — убрать. Первый шаг уровня бесплатен один раз за всё время, остальные стоят по 2 гексика; цена и баланс видны рядом. Номера показывают порядок, предыдущие шаги остаются видимыми. Маркеры не являются блоками и не принимают клики; действия выполняются через грани настоящих кубиков. В аркаде подсказок нет.
- Обычный режим показывает цели; «Ошибки» включает сравнение цветами: зелёный — совпало, жёлтый — не хватает, красный — лишнее, тёмный — правильно пусто.

Уровни открываются последовательно и сгруппированы по пять. Финальное поздравление появляется после последнего уровня, без автоматического возврата к первому. Повторное прохождение сохраняет отметки. Измерения новых задач: [docs/levels-11-30.md](docs/levels-11-30.md).

## Мотя и гардероб

Мотя — оригинальная плюшевая моль пользователя. Классический костюм доступен сразу, пять выдаются в подарках, седьмой — эксклюзивная награда кампании:

| ID | Образ | Редкость |
|---|---|---|
| classic | Классическая Мотя | Базовая |
| sleepy | Сонная Мотя | Легендарная, подарок |
| baker | Мотя-кондитер | Обычная, подарок |
| winter | Зимняя Мотя | Обычная, подарок |
| wizard | Мотя-волшебница | Легендарная |
| cosmic | Космическая Мотя | Редкая, подарок |
| royal | Королева Мотя | Эксклюзивная, за всю кампанию |

Выберите карточку, посмотрите три эмоции и нажмите **«Надеть»**. Предпросмотр не применяет костюм и не отправляет события контроллеру игровых эмоций. Отметка «Надето» обозначает используемый костюм.

Изображения извлечены без редактирования из предоставленного архива `motya_6_skins_18_emotions.zip`: `public/assets/motya/<skin>/idle.png`, `sad.png`, `shock.png`. Все 18 PNG — RGBA 1024×1024 с прозрачным фоном. Совпадение с архивом проверено по SHA-256.

Один контейнер и один `img` переиспользуются в игре, гардеробе и поздравлениях. `object-fit: contain` сохраняет пропорции; фиксированный квадратный контейнер предотвращает скачки размера. Старый запрос декодирования не может вернуть предыдущую эмоцию или костюм. Никаких дополнительных слоёв персонажа нет.

Королева открывается только при наличии всех 30 настоящих идентификаторов в списке пройденных уровней. Открытый последний уровень, количество записей, повторения и посторонние названия не считаются прохождением. До получения доступны карточка с замком и три предпросмотра, а «Надеть» заблокирована. Способ получения — только `campaign-30`; `canDropFromGifts` и `canPurchase` равны false.

Постоянное право хранится отдельно в `hexanexus.motya.royal.v1`. При чтении старого полностью завершённого прогресса награда выдаётся автоматически и без обязательного поздравления. Новое живое завершение показывает компактное сообщение в финальном окне и кнопку «Посмотреть в гардеробе». Повторные старты и перепрохождения не повторяют сообщение. Надетый скин по-прежнему записывается в `hexanexus.motya.skin.v1`.

Три оригинальных королевских PNG 1254×1254 извлечены без изменений из `motya_royal_3_emotions.zip` в `public/assets/motya/royal/`; прозрачность и совпадение с архивом проверены. Всего в APK 21 PNG для семи костюмов.

Каталог `src/motya-skins.ts` хранит редкость, доступность и способ получения. Стартовые шансы подарков по редкостям — 60% обычные, 25% редкие, 15% легендарные. Полученные наряды исключаются; веса оставшихся редкостей нормализуются. Реальных платежей и рекламы нет.

Состояния IDLE/SAD/SHOCK и победные анимации сохранены. В словаре 79 оригинальных фраз, последние три исключаются при достаточном выборе. Похвала за установку доступна только при уменьшении несовпадений; остальные ходы получают нейтральные ответы.

## Сохранения и настройки

- `hexanexus.progress.v2` — прежние отметки прохождения, текущий уровень, обучение и кубики.
- `hexanexus.music` — прежние настройки музыки.
- `hexanexus.phoebe.enabled` — прежний технический ключ видимости помощницы, сохранён для совместимости; в интерфейсе называется «Показывать Мотю».
- `hexanexus.motya.skin.v1` — отдельный строковый ID надетого костюма. При отсутствии, неизвестном ID или отказе чтения используется `classic`.

Скины не изменяют прогресс и музыкальные настройки. Примерка работает даже при скрытой помощнице. Покупка, владение костюмами, версия миграции и ожидающий результат хранятся вместе с балансом в `hexanexus.economy.v1`. При ошибке записи покупка не выполняется; при ошибке сохранения надетого костюма сохраняется прежний выбор.

Либо откройте `/?editor=1` на dev-сервере. Код редактора сохранён в `src/dev-editor.ts`, `src/dev-editor.css` и `src/editor.ts`. Доступны изменение основы и целей, 24 ориентации, проверка, JSON-импорт/экспорт и испытание задачи.

## Android APK

Публичный APK: `release/Hexanexus-v1.2.0.apk`. Оригинал Gradle: `android/app/build/outputs/apk/release/app-release.apk`. Android versionName — `1.2.0`, versionCode — `3`. Это подписанная release-сборка без отладки приложения и WebView, с production веб-ресурсами; редактор исключён. Прежний APK 1.1.0 и локальная тестовая сборка сохранены отдельно.

```sh
npm.cmd test
npm.cmd run arcade:simulate
npm.cmd run android:release
```

Скрипт валидирует уровни, проверяет TypeScript, собирает веб-версию, синхронизирует Capacitor, запускает Gradle, копирует APK и проверяет подпись и содержимое. Он завершается с ошибкой при сбое любого этапа.

Настроены Capacitor 8, JDK 21, SDK Platform 36 и Gradle Wrapper. Локальные инструменты находятся в `.tools`; также поддерживаются JAVA_HOME и ANDROID_HOME / ANDROID_SDK_ROOT. Первая подготовка инструментов может требовать сети, готовая игра работает офлайн без компьютера, внешнего сервера и дополнительных файлов. Разрешение INTERNET отсутствует.

Пакет `com.hexanexus.puzzle`, название «Гексанексус». Публичная сборка использует вариант **release**, отладка приложения и WebView отключена. Для совместимости сохранён прежний сертификат Android Debug из исходного ключа; новый ключ не генерируется. Устанавливайте поверх предыдущей версии, не удаляя приложение. Сохраняйте `.tools/android-user-home/debug.keystore` для совместимых будущих обновлений; ключ не включается в Git и APK. Нужен Android 7.0+ с WebGL в System WebView. Для разработки остаётся `npm.cmd run android:apk` (debug, `release/Hexanexus-Android.apk`). APK распространяются через GitHub Releases, без хранения бинарного файла в исходниках.

## Проверки

```sh
npm.cmd test
npm.cmd run motya:validate
npm.cmd run build
npm.cmd run android:verify
```

264 теста, TypeScript, production build и Gradle assembleRelease прошли для 1.2.0. Проверены прозрачность 21 PNG, безопасное чтение и сохранение костюма, гонки декодирования, старые настройки и неизменность музыки. APK-проверка сверяет все PNG с исходниками, музыку по SHA-256, 30 уровней, реплики, applicationId, версию, сертификат и наличие аркадного режима; требует отсутствия старых спрайтов и публичного редактора. Симуляция аркады: 30 000 раундов на трёх seed. Подробный отчёт 1.2.0 — `docs/arcade-1.2.0.md`; ниже также сохранены сведения о проверках предыдущих функций.

В Chrome проверены все 18 предпросмотров, шесть игровых цепочек IDLE → SAD → IDLE → SHOCK → IDLE, один спрайт на каждом проверенном кадре, быстрое переключение костюмов, сохранение после перезапуска и возврат к classic при неизвестном ID. Гардероб проверен на 360×780, 390×844, 430×932, 768×1024, 1440×1000 и 844×390. Проверены публичные адреса без редактора и работа сохранённого dev-редактора.

Прежний переключатель прозрачных ячеек заменён пошаговым поиском решения. Подробности и результаты текущей проверки: `docs/step-hints-1.2.0.md`.

Отчёты находятся в `artifacts/motya-assets.json`, `artifacts/motya-browser-qa.json` и `artifacts/apk-verification.json`; эти диагностические файлы не входят в Git.

Пошаговые подсказки проверены для 30/30 уровней и 120 состояний, включая ошибочные установки. Поиск выполняется в ограниченном Worker; цепочка виртуальная и не меняет реальные данные. Команда: `npm.cmd run hints:validate`. Отчёты: `artifacts/hints-validation.json`, `artifacts/step-hints-browser-qa.json`.

Проверки Королевы Моти: `src/campaign-rewards.test.ts` покрывает реальное завершение, старые сохранения, одноразовую награду, постоянное право и запрет надевания закрытого образа. В production-браузере награда получена последним легальным 3D-ходом, проверены переход в гардероб, сохранение royal после перезапуска и отсутствие повторного поздравления. Отчёт: `artifacts/royal-browser-qa.json`.

Иконка приложения — оригинальная Мотя-волшебница с сияющим кубиком из `hexanexus_motya_app_icons.zip`. Android использует обычные и круглые `mipmap-*/ic_launcher*.png` для пяти плотностей, а на Android 8+ — адаптивные XML в `mipmap-anydpi-v26` со слоями `drawable-nodpi/motya_launcher_*.png`. Системный экран запуска использует ту же иконку. Веб-иконки находятся в `public/icons`; `index.html` ссылается на `/icons/favicon.ico` и Apple touch icon. Копия `public/favicon.ico` оставлена для обычных браузеров; явная ссылка обходит встроенный перехват пути `/favicon.ico` в Android Capacitor. PWA-манифест не используется. `android:verify` проверяет ресурсы внутри APK, совпадение иконок с исходными PNG/ICO и ссылки AndroidManifest/adaptive XML; отчёт — `artifacts/app-icons-verification.json`.
