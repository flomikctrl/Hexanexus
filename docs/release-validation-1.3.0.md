# Проверка релизной сборки Hexanexus 1.3.0

Версия 1.3.0, Android versionCode 4, applicationId `com.hexanexus.puzzle`, Android 7.0+ (minSdk 24). Игровая логика и сохранения при подготовке релиза не изменялись.

## Выполненные проверки

- 408 автоматических тестов в 21 файле прошли.
- TypeScript-check и production build прошли.
- Все 30 уровней прошли валидатор достижимости.
- Проверены все 21 оригинальный прозрачный PNG Моти для семи костюмов.
- Повторно выполнены браузерные проверки подарков, миграции, вероятностей, надевания, ошибок записи и сохранения результата; используется отдельный профиль.
- Повторно проверены экраны и модальные макеты на 360×640, 390×844, 430×932, 844×390 и 1440×1000.
- `npm.cmd run android:release` прошёл. APK-аудит подтвердил прежнюю подпись, комплектность уровней, костюмов, музыки, монеты и иконок, настройку безопасной области, отсутствие INTERNET, редактора, отладки, инструментов разработки и ключей подписи внутри APK.
- Функциональные проверки Samsung A55 выполнялись на предшествующей тестовой сборке с теми же игровыми веб-ресурсами; см. [подарки](gifts-1.3.0.md), [safe area](safe-area-1.3.0.md), [Android Back и лобби](qol-1.3.0.md). В ходе этой финальной подготовки данные телефона не изменялись; повторная проверка release APK на устройстве не заявляется.

Технические результаты хранятся в документации разработчика. Публичное описание содержит только пользовательские изменения: [релиз 1.3.0](releases/v1.3.0.md).
