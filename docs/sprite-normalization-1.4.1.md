# Hexanexus 1.4.1 — нормализация костюмов

22 ноября 2026. Публикация, commit, push и tag не выполнялись.

## Исправления

- Девять PNG baker/winter/cosmic нормализованы из исходного архива: видимая ширина 930–944 px на прозрачном холсте 1024×1024, центр x≈512, лапки y≈999. У каждого костюма один коэффициент равномерного масштабирования для трёх эмоций. Удалены только изолированные обрывки исходного листа (26–149 пикселей); акценты SHOCK сохранены. Другие 27 PNG не менялись.
- Исходные фигуры занимали примерно 420×325 px, тогда как классический и сонный костюмы — примерно 940×770 px. CSS костюмов и индивидуальные масштабы не добавлялись.
- Список гардероба прокручивается внутри отдельной области; панель «Надеть» занимает собственную строку grid и не перекрывает карточки. Сохранены native safe area и нижние отступы env(safe-area-inset-bottom).
- package.json/package-lock.json и Android синхронизированы: 1.4.1, versionCode 7 (был 6). Версия видна в меню и настройках.

## Проверки

- 543 автоматических теста, TypeScript, production build, Android release build — успешно.
- Валидатор проверил прозрачность и размер всех 36 PNG, дополнительно масштаб, центр и посадку девяти заменённых спрайтов.
- Изолированный Chrome: ширины 360/390/430/1440 px, отсутствие перекрытия последнего ряда и горизонтального переполнения, девять эмоций, предпросмотр в профиле и игровой сцене, версия 1.4.1. Профиль и экономика тестовой копии не изменились.
- Реальный Samsung Galaxy A55: обновление через adb install -r, девять эмоций в гардеробе, последний ряд целиком над панелью, доступная кнопка «Надеть», версия в настройках и меню. Костюмы не надевались, покупки не совершались, старые резервные копии не восстанавливались.
